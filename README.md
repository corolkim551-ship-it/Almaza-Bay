# Winter Project Pro V4

A redesigned executive operations UI for Winter Project.

### Demo credentials
- Admin: `Admin` / `admin00` — add, edit and delete projects.
- Operator: `operator` / `operator00` — add projects only.

### Workspaces
Winter Project, Maintenance and Manufacturing are isolated workspaces with separate project data and progress.

### Project controls
Hotel filter, status filter (Completed / On Going / Not Started), department filter (Kitchen / Engineering / HR / IT / FO / FB / Recreation), search, add, edit and delete.

The uploaded Almaza Bay photo is included in `assets/almaza-bay.jpg` and used in the login and dashboard hero.

This is a front-end presentation prototype. Authentication is client-side for demonstration; production use should connect to a secure backend and database.
